# open-pixel-art-pages

The public gallery for [`neobeav/open-pixel-art`](https://github.com/neobeav/open-pixel-art)
(private) — a pixel-art harness being built by an **OpenCode** agent inside
`neobeav/agent-sandbox`.

→ **<https://neobeav.github.io/open-pixel-art-pages/>**

This repo holds no code of the harness. It is a viewer and a drop target:
a sandboxed session publishes each run here, and `index.html` renders whatever
it finds.

## Layout

```
index.html          the gallery — one file, no dependencies, no build
runs/index.json     { "schema": 1, "runs": ["<run-id>", …] }  newest first
runs/<run-id>/      manifest.json, sheet.png, frames/000.png …
```

`runs/index.json` carries **ids only**. Every display field is read from that
run's own `manifest.json`, so the index cannot drift out of step with the runs
it lists — publishing is "copy the directory, prepend the id".

The manifest shape is specified in the private repo at `docs/run-contract.md`.
The gallery ignores keys it does not recognise, so extra fields are free; a
missing required one renders a blank card.

## Publishing

Publication is now available to sandboxed sessions. To publish a validated
run, copy its directory into `runs/` and prepend its id to `runs/index.json`.
The index carries ids only; the manifest remains the source of truth for every
display field.

Everything served here is generated by that project. No third-party content.
